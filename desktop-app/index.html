🖨️ MoreTranz Printer Configuration

Configure your printer settings for automatic printing

✨ Easy Setup Option:

Download the config.json file from the Dashboard in the web app. It will be pre-configured with your credentials!

Just download it, and the app will automatically load it from your Downloads folder on first run.

📌 Manual Setup (if needed):
  1. Open MoreTranz web app → Dashboard
  2. Click "Download Config Only" button
  3. Or manually: Open Developer Tools (F12) → Application → Local Storage → Copy "token"
Attachments will be saved in folders named by PO number (e.g., {PO_number}/filename.pdf)
